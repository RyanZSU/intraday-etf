> 仅供学习 / 回测 / 模拟，不构成投资建议。做T是负和博弈，多数人亏损。

## 环境变化（重要）

你的 **miniQMT 已禁用**，不能用 `xtquant` 外接 Python 了。
完整 QMT 的正确用法是**在客户端「内部」写策略**，有两种语言：

| 语言 | 说明 | 推荐 |
|---|---|---|
| **Python 策略** | 本目录的 `.py` 文件，API 是 `ContextInfo` + `passorder` | ✅ 首选（你会 Python） |
| VBA 策略 | QMT 传统策略语言 | 备用 |

> 中文/部分老版本 QMT 若没有 Python 策略入口，告诉我，我帮你把策略转成 VBA。

## 核心规则（不变）

- 只有 **T+0 ETF** 能当日买卖做T（个股、境内股票ETF都是 T+1）。
- 选品三要素：T+0 + 日均成交额>1亿 + 日内振幅够。
- 推荐标的：黄金 518880（网格/趋势）、恒生科技 513130、纳指 513100（趋势）。
- ETF 免印花税，佣金谈「万1 + 免5」。

## 使用步骤（在 QMT 客户端内操作）

1. **改参数**：打开 `strategies/grid_trading.py`，把顶部 `ACC_ID` 改成你的资金账号（登录界面可见），`STOCK` 改成你要做的标的。
2. **新建策略**：QMT 客户端 →「策略」/「量化策略」→「新建 Python 策略」，把文件内容粘进去（或导入文件）。
3. **运行设置**：股票池选对应标的，周期选「1分钟」。
4. **先回测**：策略的运行模式选「回测」，设置回测时间段，先看扣费后赚不赚钱、最大回撤多少。
5. **再模拟**：运行模式切「模拟」，跑 1–2 周，确认下单/成交/方向正常。
6. **最后小资金实盘**：1–2 万起步，跑通一个月再说。

## 通用风控参数（5 个策略文件顶部都有）

每个策略 `init` 前都带两个风控参数：

- `FLAT_MINUTES = 890` —— 收盘前自动平仓时间（890 = 14:50，可调；设 `99999` 关闭）。
- `STOP_LOSS_PCT = 0.02` —— 硬止损：跌破持仓平均成本 2% 清仓**并当日暂停**（设 `0` 关闭）。

触发平仓依赖行情能取到 K 线时间戳。若你的 QMT 版本取不到时间（`get_market_data_ex` 返回不带时间的 list），这两个功能会静默失效——请告诉我，我改成按 bar 计数的方式。

## 风控铁律

1. 单标的日内仓位别超过总资金一小部分。
2. 网格/趋势在单边行情都会吃亏，**务必设止损**（跌破成本 X% 无条件清仓）。
3. 14:57 之后不开新仓（跨境 ETF 尾盘流动性差+折溢价回归）。
4. 做纳指/港股 ETF 前先看隔夜外盘。
5. 手续费没谈「免5」就别高频做T。
